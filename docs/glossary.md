# Glossary

Terms used in SolidBuilder documentation, one line each.

| Term | Meaning |
|---|---|
| Animation sequence | Time-based tracks of keyed component, camera, visibility and callout actions on an assembly |
| Annotation plane | Plane on which 3D annotations are placed and read |
| Assembly | Component definition made of occurrences related by joints and constraints |
| Assembly variant | Set of fitted, not-fitted and substituted components of a schematic and board |
| Assembly constraint | Geometric relation between occurrences (mate, flush, angle, tangent, insert, symmetry, center) |
| Base feature | History entry holding imported or history-free geometry |
| Application connector | Add-in inside another application that exchanges data with SolidBuilder through that application's public interface |
| Bill of materials | Derived list of items and quantities of an assembly |
| Board | Printed circuit board object with outline, stack-up, footprints, copper and rules |
| Body | Solid, sheet, wire, mesh or subdivision geometry owned by a part |
| BOM item | One row of a bill of materials |
| Branch | Parallel line of versions of a document that can be merged |
| Broken reference | Persistent reference that resolves to no entity or to several |
| Change set | Ordered transactions exchanged for merges and multi-user editing |
| Component definition | Part or assembly that can be placed as occurrences |
| Design block | Reusable circuit saved with ports and parameters |
| Component generator | Tool that creates calculated machine elements and keeps their inputs |
| Configuration | Variant of a component definition, one row of its configuration table |
| Configuration table | Table of configurations (rows) and configurable aspects (columns) |
| Connection definition | Named connection frames stored on a component for automatic placement |
| Connection frame | Coordinate frame on component geometry used as a joint anchor |
| Contact set | Occurrences treated as solid during drags and drives |
| Cut list | Grouped frame members with lengths, end angles and quantities |
| Datum feature | Labeled face or feature used to establish a datum reference frame |
| Decal | Image applied to faces for display |
| Design rule check | Evaluation of a board against its clearance, width, hole and manufacturing rules |
| Direct edit | Change applied to faces of a body rather than to feature inputs |
| Display state | Saved visibility, appearance overrides and camera |
| Drive joint | Animation of a joint value through a range |
| Exchange package | Open container that connectors read and write |
| Exploded state | Saved displacement steps of occurrences for presentation |
| External reference | Link from one document to a definition in another document |
| Feature | History entry that creates or modifies bodies |
| Feature control frame | Geometric tolerance with characteristic, zone, modifiers and datums |
| Feature group | Named contiguous range of history entries |
| Feature history | Ordered list of entries evaluated to produce a part's bodies |
| Feature template | Saved set of features with inputs and parameters for reuse |
| Flat pattern | Unfolded state of a sheet metal part |
| Freeform subdivision body | Body shaped by editing a control cage of a subdivision surface |
| Health list | List of warnings and errors of the feature histories in a document |
| Fabrication output | File written from a board for manufacturing, such as Gerber, drill or IPC-2581 data |
| Import record | Record of an import's source, options, reader version and identifier map |
| Lightweight loading | Opening an assembly with display data only and exact geometry on demand |
| Licensed bridge | User-installed, user-licensed conversion library called as a separate process |
| Library family | Sized family of standard components defined by a template and a size table |
| Linked import | Imported base feature that re-reads its source file when it changes |
| Live rules | Geometric relations kept automatically during direct edits |
| Loss report | List of content an import or export could not represent |
| Model state | Stage of a configuration with suppression and parameter overrides |
| Motion coupling | Ratio relation between two joint values |
| Named version | Protected, named version of a document |
| Netlist | Derived list of nets and their component pins |
| Occurrence | Placement of a component definition in an assembly |
| Operation journal | Record of element-level operations behind undo, history and merges |
| Open reader | Native reader for a format with a published specification or a permissively licensed reader |
| Package with references | Folder or archive with a document and everything it references |
| Parameter | Named, unit-aware value or expression |
| Part | Component definition that owns bodies, usually through a feature history |
| Persistent reference | Reference to a face, edge or vertex by persistent name and signature |
| Plug-in feature | Feature type provided by a sandboxed WebAssembly plug-in |
| Position state | Saved joint values of an assembly |
| Preserved foreign data | Imported content kept unmodified because it has no SolidBuilder equivalent |
| Reference geometry | Datum planes, axes, points and coordinate systems |
| Revision | Released state label of an item managed by Arc Hub |
| Ratsnest | Display of connections not yet routed |
| Rigid group | Occurrences locked relative to each other |
| Rollback marker | Position in a feature history after which entries are not evaluated |
| Round-trip map | Table of host identifiers and SolidBuilder IDs that keeps repeated exchanges consistent |
| Rule | Expression, script or graph that sets model values or runs commands on events |
| Schematic | Set of sheets that define the electrical connections of a board |
| Sheet metal rule | Material, thickness, bend and relief settings of a sheet metal part |
| Signal-integrity check | Basic check of impedance, delay, coupling or return path of a net |
| Simplified representation | Envelope or wrapped substitute body for a subassembly |
| SPICE study | Circuit simulation of a schematic through an open engine |
| Standard parts library | Catalog of sized standard components |
| Text form | Canonical, diffable text listing of a component's feature history |
| Weld | Weld bead or cosmetic weld with symbol data in a weldment |
| Weldment | Assembly with preparation, weld and machining stages |
| Workspace | Folders and search paths used to resolve external references |
